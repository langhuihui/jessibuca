打包版 HLS Video Web Components 演示

说明：这个页面展示了打包了 HLS.js 的 Web Components，无需额外加载任何外部库。 Web Components 已经包含了所有必要的功能。

1. 简化版 Web Component

文件大小小，功能专注于基本播放需求

<script src="dist/simple-hls-video.min.js"></script> <simple-hls-video src="video.m3u8" controls autoplay muted></simple-hls-video>

2. 完整版 Web Component

功能丰富，包含画质控制和高级功能

<script src="dist/hls-video.min.js"></script> <hls-video src="video.m3u8" controls debug></hls-video>

3. ES Module 使用方式

在支持 ES 模块的现代环境中使用

// 导入简化版 import 'dist/simple-hls-video.esm.js'; // 或导入完整版 import 'dist/hls-video.esm.js'; // 在 HTML 中使用 <simple-hls-video src="video.m3u8" controls></simple-hls-video>

4. 框架集成示例

Vue 3

// main.js import 'dist/simple-hls-video.esm.js'; // Component.vue <template> <simple-hls-video :src="videoUrl" controls @play="onPlay" @pause="onPause" ref="player" ></simple-hls-video> </template> <script setup> import { ref } from 'vue'; const player = ref(null); const videoUrl = ref('video.m3u8'); const onPlay = () => console.log('播放开始'); const onPause = () => console.log('播放暂停'); </script>

React

// App.js import React, { useRef, useEffect } from 'react'; import 'dist/simple-hls-video.esm.js'; function VideoPlayer() { const playerRef = useRef(null); useEffect(() => { const player = playerRef.current; const handlePlay = () => console.log('播放开始'); const handlePause = () => console.log('播放暂停'); player.addEventListener('play', handlePlay); player.addEventListener('pause', handlePause); return () => { player.removeEventListener('play', handlePlay); player.removeEventListener('pause', handlePause); }; }, []); return ( <simple-hls-video ref={playerRef} src="video.m3u8" controls /> ); }

5. 构建说明

构建命令

# 构建 HLS.js 库 npm run build # 构建 Web Components npm run build:webcomponents # 构建所有 npm run build:all # 开发模式（监听变化） npm run dev:webcomponents

输出文件

  • web-components/dist/simple-hls-video.js - 简化版 IIFE 格式
  • web-components/dist/simple-hls-video.min.js - 简化版压缩版
  • web-components/dist/simple-hls-video.esm.js - 简化版 ES 模块
  • web-components/dist/hls-video.js - 完整版 IIFE 格式
  • web-components/dist/hls-video.min.js - 完整版压缩版
  • web-components/dist/hls-video.esm.js - 完整版 ES 模块

文件大小对比

  • 简化版：~200KB (压缩后)
  • 完整版：~300KB (压缩后)
  • 原始 HLS.js：~250KB
